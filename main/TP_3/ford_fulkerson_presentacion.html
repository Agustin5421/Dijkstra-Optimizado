Ford–Fulkerson

Cómo calcular cuánto puede circular, como máximo, por una red con capacidades limitadas.

El problema

¿Cuánto flujo puede llegar de A a H?

Una red dirigida, como un sistema de caños. El flujo sale del origen A y llega al destino H. Cada arista tiene una capacidad máxima.

Capacidad

0 ≤ f(u,v) ≤ c(u,v)

Por una arista no puede pasar más de lo que soporta.

Conservación

lo que entra = lo que sale

En cada nodo intermedio no se pierde ni se acumula flujo.

La idea

Buscar el camino que deja pasar más y restarlo

  1. flujo ← 0
  2. mientras haya un camino de A a H con lugar:
  3. P ← el camino que deja pasar el valor mayor
  4. b ← menor capacidad que queda en P
  5. para cada arista (u,v) de P:
  6. residual(u,v) −= b
  7. residual(v,u) += b
  8. flujo += b
  9. devolver flujo

Bloquear caminos

Al restar, la arista más chica del camino queda en 0 y se bloquea. Cuando todos los caminos a H están bloqueados, terminamos.

Valor de un camino

Lo limita su arista más chica. Entre todos los caminos, elegimos el de valor mayor.

Arista inversa

Al mandar flujo de u a v se habilita v → u. Sirve para deshacer una mala elección.

Las aristas que salen de S están llenas. Es imposible mandar más de 15: el resultado es óptimo.

Código en Python

La implementación

def ford_fulkerson(grafo, fuente, sumidero):
    residual = construir_residual(grafo)
    flujo_maximo = 0
    caminos = []

    while True:
        camino = buscar_camino(residual, fuente, sumidero)
        if camino is None:
            break

        aristas = list(zip(camino, camino[1:]))

        cuello = min(residual[u][v] for u, v in aristas)

        for u, v in aristas:
            residual[u][v] -= cuello
            residual[v][u] += cuello

        flujo_maximo += cuello
        caminos.append((camino, cuello))

    return flujo_maximo, caminos
1. Preparar: crear la red residual e iniciar el flujo.
2. Buscar: encontrar un camino; si no existe, terminar.
3. Actualizar: calcular el cuello de botella y ajustar las capacidades residuales.
4. Acumular: sumar el flujo, guardar el camino y devolver el resultado.

Código en Python

Elegir el camino de valor mayor

def buscar_camino(residual, origen, destino):
    mejor = {origen: float("inf")}
    anteriores = {origen: None}

    pq = [(-float("inf"), origen)]

    while pq:
        valor_actual, u = heapq.heappop(pq)
        valor_actual = -valor_actual

        if u == destino:
            break

        for v, capacidad in residual[u].items():
            nuevo_valor = min(valor_actual, capacidad)

            if nuevo_valor > mejor.get(v, 0):
                mejor[v] = nuevo_valor
                anteriores[v] = u
                heapq.heappush(pq, (-nuevo_valor, v))

    if destino not in anteriores:
        return None

    return reconstruir_camino(anteriores, origen, destino)
1. Preparar: registrar el mejor valor y crear la cola de prioridad.
2. Elegir: extraer el camino de mayor valor y detenerse al llegar al destino.
3. Explorar: comparar el cuello de botella de cada vecino y actualizar los mejores caminos.
4. Reconstruir: devolver el camino encontrado, o None si no existe.
Cierre

Complejidad y usos

Complejidad

O(E · f*)

En general hay a lo sumo f* iteraciones (f* = flujo máximo). Elegir siempre el camino de valor mayor reduce mucho las iteraciones: acá bastaron 4.
